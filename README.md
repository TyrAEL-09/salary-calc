# Calculadora de Salario

Aplicacion web estatica para calcular el salario mensual a partir de un calendario.

## Funciones

- Seleccionar los dias trabajados en el mes
- Definir sueldo por hora y horas por defecto para cada dia de la semana
- Sobrescribir horas o tarifa en una fecha concreta
- Ver el total acumulado del mes en tiempo real

## Archivos

- `index.html`
- `styles.css`
- `script.js`

## Uso local

Solo abre `index.html` en el navegador.
